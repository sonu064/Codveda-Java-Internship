## How to Run Any Project

1. Navigate to the task folder (e.g. `Level-1/Task-1-Basic-Calculator`).
2. Open the folder in your IDE and mark `src` as Sources Root.
3. Run `Main.java`.

Or compile from the command line — each task's `README.md` has specific instructions.
